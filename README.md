# BankLedger

A batch-oriented banking ledger system implemented in COBOL.

## Status

🚧 Under development

## Overview

BankLedger is a batch-oriented banking ledger system designed to simulate
core financial transaction processing using COBOL.

The project is being developed incrementally to demonstrate:

- COBOL programming
- Batch processing
- File-based data processing
- Transaction validation
- Financial operations
- Audit logging
- Error handling
- Automated testing
- Continuous integration
